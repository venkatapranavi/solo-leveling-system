# ⚔️ Solo Leveling: Real-Life Gamification System

A dark-fantasy productivity and habit tracking web application inspired by *Solo Leveling*. The system enforces strict daily accountability across fitness, academics, and screen-time reduction using AI-driven multimodal verification.

## ⚡ Core Features

- **Awakening Cinematic Sequence**: Immersive dark gate entrance featuring celestial phases and ticking runic astral clocks.
- **Hunter Onboarding Contract**: Configures target life goals, personalized insecurities, and calibrated fear penalties.
- **24-Hour Astral Mana Clock**: Real-time celestial countdown warning of midnight penalty boundaries.
- **AI Anti-Cheat Verification**: Multimodal verification analyzing proof photos (notes, terminal code, gym logs) and generating 3 dynamic test questions.
- **Inescapable Penalty Zone**: Tab-surveillance enforcement that detects window blurring and adds punishment time for evasion attempts.
- **Ascension RPG Engine**: Live progression across Strength (STR), Agility (AGI), Intelligence (INT), Vitality (VIT), and Discipline (DIS).

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Custom animations & manhwa glow filters)
- **Graphics & Sound**: HTML5 Canvas API, Web Audio API (Synthesized SFX)
- **AI Engine**: Google Gemini API (Multimodal Vision & Question Generation)
- **Deployment**: Vercel / GitHub Pages
